# ブロックチェーン統合ガイド

このプロジェクトは、ローカル環境で動作するブロックチェーン統合を実装しています。

## セットアップ手順

### 1. 依存関係のインストール

```bash
npm install
```

### 2. Hardhatローカルノードの起動

新しいターミナルウィンドウで、Hardhatローカルノードを起動します：

```bash
npm run node
```

このコマンドは、ローカルブロックチェーンネットワークを `http://127.0.0.1:8545` で起動します。

### 3. コントラクトのコンパイルとデプロイ

別のターミナルウィンドウで、コントラクトをコンパイルします：

```bash
npm run compile
```

次に、ローカルノードにコントラクトをデプロイします：

```bash
npm run deploy:local
```

デプロイが完了すると、コントラクトアドレスが表示されます。このアドレスを `src/config/contract.ts` の `HOTEL_NFT_CONTRACT_ADDRESS` に設定してください。

または、環境変数として設定することもできます：

```bash
# .env.local ファイルを作成
NEXT_PUBLIC_CONTRACT_ADDRESS=0x...（デプロイされたアドレス）
```

### 4. フロントエンドの起動

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## ウォレット接続

1. ブラウザにMetaMaskなどのウォレット拡張機能をインストール
2. MetaMaskでHardhatローカルネットワークを追加：
   - ネットワーク名: Hardhat Local
   - RPC URL: http://127.0.0.1:8545
   - チェーンID: 31337
   - 通貨記号: ETH
3. ヘッダーの「ウォレット接続」ボタンをクリックして接続

## Hardhatアカウント

Hardhatローカルノードは、デフォルトで10個のテストアカウントを生成します。これらのアカウントは、MetaMaskにインポートして使用できます。

アカウントの秘密鍵は、Hardhatノードの起動時にコンソールに表示されます。

## 機能

- ✅ ERC-721 NFTコントラクト（HotelNFT）
- ✅ ブロックチェーンからのNFTデータ取得
- ✅ ウォレット接続（MetaMask対応）
- ✅ NFT購入機能
- ✅ モックデータへのフォールバック

## トラブルシューティング

### ブロックチェーンからNFTを読み込めない

1. Hardhatローカルノードが起動しているか確認
2. コントラクトが正しくデプロイされているか確認
3. `src/config/contract.ts` のコントラクトアドレスが正しいか確認

### ウォレット接続できない

1. MetaMaskがインストールされているか確認
2. HardhatローカルネットワークがMetaMaskに追加されているか確認
3. ブラウザのコンソールでエラーメッセージを確認

## 開発メモ

- コントラクトの変更後は、再コンパイルと再デプロイが必要です
- ローカルノードを再起動すると、すべてのデータがリセットされます
- 本番環境では、適切なネットワーク（Ethereum、Polygonなど）を使用してください
